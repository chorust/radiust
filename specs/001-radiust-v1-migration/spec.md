## User Scenarios & Testing *(mandatory)*

### User Story 1 - 查找并获取可信雷达数据 (Priority: P1)

科研和数据使用者希望查看可用来源、产品与站点，按最新时次、指定时次或时间范围获取有明确时间、物理含义和空间定位的数据，不再依赖旧生产系统。

**Why this priority**: 这是独立项目最小可用闭环，也是后续迁移与输出能力的共同基础。

**Independent Test**: 使用一个单图来源的真实离线样本，完成来源查询、精确时次获取和默认文件导出，再读回验证数据事实。

**Acceptance Scenarios**:

1. **Given** 最小安装且无公网，**When** 列出来源与产品，**Then** 返回稳定排序的目录、能力及依赖状态，某个来源缺少可选依赖不影响其他来源。
2. **Given** 来源具有可用帧，**When** 按最新或精确时次获取，**Then** 返回正确来源、产品、站点、有效时间、起报时间、变量、单位、质量标记和原生网格，获取本身不隐式写正式文件。
3. **Given** 时区明确的范围，**When** 查询多个时次，**Then** 只返回起点包含、终点不包含的结果；不支持历史查询的来源明确拒绝请求。
4. **Given** 零帧、多帧、过期帧或无时区输入，**When** 请求单帧，**Then** 分别报告无数据、歧义、过期或参数错误，不选相邻时次替代。
5. **Given** 最小安装与可用样本，**When** 执行默认下载，**Then** 在当前目录的 data 下得到可读回的 NetCDF，保留数值、质量、坐标、空间参考和处理来源信息。

---

### User Story 2 - 正确解释颜色、质量与空间位置 (Priority: P1)

分析人员希望不同来源的图像、瓦片和科学产品遵守统一的数据含义，避免把缺测、未知颜色或无回波误当成无雨。

**Why this priority**: 错误的物理值与位置会直接损害后续分析，即使文件成功下载也不能接受。

**Independent Test**: 对已知颜色、透明像素、参考点和不同网格的样本验证值与质量；显式转换网格后检查参考点与缺测边界。

**Acceptance Scenarios**:

1. **Given** 同一图像采用不同调色板索引顺序，**When** 解码或拼接，**Then** 得到相同物理值、颜色和透明度；默认未知颜色报错，显式宽容模式保留缺测并标记未知颜色数量。
2. **Given** 样本含有雨、无雨、缺测、站外与低于检测阈值区域，**When** 解码，**Then** 各状态按来源证据区分，无依据的无回波不赋值为零反射率，等级产品不冒充精确雨强。
3. **Given** 瓦片缺失，**When** 获取产品，**Then** 默认失败；仅来源明确允许部分覆盖时返回带缺测质量标记的产品。
4. **Given** 原生极坐标或投影网格，**When** 默认获取，**Then** 保持原生几何；显式转换时记录目标、方法与假设，类别只允许最近邻，反射率双线性插值遵守线性反射率物理含义。
5. **Given** 无可靠地理定位或目标参数不足，**When** 请求空间转换，**Then** 明确失败，不以坐标改名代替转换。

### User Story 3 - 可重复且完整地保存科学数据和原始资料 (Priority: P1)

数据维护者希望周期性运行同一下载任务，并将科学数据和所需原始资料完整保存到本地或对象存储；中断、修订和重跑不能产生假成功或错误覆盖。

**Why this priority**: 可靠交付决定数据能否用于持续采集与离线复核。

**Independent Test**: 使用同一帧执行首次下载、重跑、补存原始资料、上游修订与故障恢复，在本地和两类对象存储验证完成状态。

**Acceptance Scenarios**:

1. **Given** 匹配身份且完整有效的输出，**When** 重跑，**Then** 可安全跳过；可变或版本未知的来源先重新校验，同路径不同身份必须报告冲突。
2. **Given** 写入任意文件时失败或取消，**When** 检查输出，**Then** 不存在可被判定为成功的完成清单，重跑可修复未完成产物。
3. **Given** 已有仅解码产物，**When** 请求同时保存 raw，**Then** 补齐全部原始资料后才成功；仅保存 raw 时不解码、不拼接、不重网格，并提供离线重放所需清单。
4. **Given** 显式覆盖请求，**When** 执行，**Then** 重新校验或获取上游并提交替代版本，对象存储旧版本保留至显式清理。
5. **Given** 不同起报时间、处理方式或版本，**When** 保存同一有效时间的数据，**Then** 输出身份可区分；自定义路径逃逸或短标识碰撞不能导致越界写入或覆盖。
6. **Given** 多变量或非规则网格，**When** 选择输出格式，**Then** 按格式能力明确要求变量选择或显式重网格，科学存档与可视化产物不混淆。

### User Story 4 - 在终端直接查看雷达 (Priority: P2)

值班和研究人员希望直接预览单帧雷达或已有文件，查看色标、时间与单位，无需先导出或启动图形应用。

**Why this priority**: 提高日常检查效率；属于 v1 必需交付，但可在数据闭环后独立验收。

**Independent Test**: 使用固定样本检验文字、ANSI 和图片终端展示，并对非交互输出和本地文件模式单独验收。

**Acceptance Scenarios**:

1. **Given** 单帧产品，**When** 请求终端展示，**Then** 显示正确方向、比例、标题、UTC 时间、变量、单位与色标，并区分无雨、缺测和站外，不写正式输出。
2. **Given** 未知终端或能力探测超时，**When** 自动展示，**Then** 有界探测后降级到 ANSI/文字；显式不兼容模式明确报错。
3. **Given** stdout 被重定向，**When** 未显式选择文字模式，**Then** 获取数据前报错；文字模式可重定向且不输出图片控制序列。
4. **Given** 本项目生成的 NetCDF 或 PNG，**When** 预览文件，**Then** 多时间或多变量数据要求明确选择；PNG 保持原样且缺失信息标为未知，不推断物理值或位置。
5. **Given** 用户调整展示尺寸或配色，**When** 渲染，**Then** 科学数据不被修改；类别、PNG 和不支持直接展示的网格拒绝不适用参数。

---

### User Story 5 - 批量运行、诊断和管理缓存 (Priority: P2)

使用者希望长时间处理多个帧时看到每帧结果，能取消任务、识别失败原因并回收缓存，同时保留正式资料。

**Why this priority**: 支持稳定的历史处理与外部定时采集。

**Independent Test**: 混合成功、失败、重复和超限样本执行批量任务，取消部分任务并清理缓存，核对逐帧报告和正式数据。

**Acceptance Scenarios**:

1. **Given** 有序多帧输入，**When** 默认批量获取，**Then** 按输入或稳定发现顺序保留每帧成功与失败；重复输入拒绝，停止模式失败后取消未完成工作并保留部分结果。
2. **Given** 大批量任务，**When** 使用流式获取，**Then** 按完成顺序交付带帧标识的结果，预取有界，不要求将全部结果同时留在内存。
3. **Given** 暂时性网络错误、认证错误或资源超限，**When** 执行任务，**Then** 仅暂时性错误按预算重试，认证与处理错误不自动重试，超限明确失败。
4. **Given** 使用中缓存、损坏缓存和已保存 raw，**When** 回收或清空缓存，**Then** 使用中条目和正式输出不被删除，损坏缓存可重新获取；禁用缓存不影响数据正确性。
5. **Given** 参数、配置和环境值互相冲突，**When** 检查有效配置，**Then** 按已规定优先级解析并显示来源，未知配置拒绝，敏感信息脱敏。
6. **Given** 部分失败、全失败、无数据或中断，**When** 命令结束，**Then** 提供可区分的退出状态与逐帧报告，诊断不污染机器报告。

### User Story 6 - 完成所有旧来源的迁移与交接 (Priority: P1)

维护者希望旧项目的全部来源，包括未启用及注释实现，都有清晰去向、真实样本和迁移证据，确认完整交接后再归档旧项目。

**Why this priority**: 全量迁移是 v1 的完成边界，框架可运行不等于迁移完成。

**Independent Test**: 将旧仓库盘点逐项与新来源目录、样本验收和例外记录核对，独立形成覆盖报告。

**Acceptance Scenarios**:

1. **Given** 可访问的旧仓库，**When** 盘点来源，**Then** 每个启用、未启用和注释实现均有产品、依赖、状态、样本来源及迁移去向。
2. **Given** 已迁移来源，**When** 离线回归，**Then** 每个来源至少一个真实样本通过发现、获取和解码契约，修正历史错误时提供迁移说明。
3. **Given** 停运或无法获取的来源，**When** 评估完成度，**Then** 记录证据与例外，不宣称在线可用；停运来源仍保留可得历史样本行为，无法取得样本必须明确列为例外。
4. **Given** 全部验收与例外清单，**When** 决定归档旧项目，**Then** 仅在无未解释遗漏、回归通过、代表在线检查完成且例外被接受后进入归档。

### Edge Cases

- 最新地址在发现与下载之间更新：必须证明获取内容对应已选帧，否则拒绝提交。
- 预报同一有效时间对应多个起报：单帧查询报歧义，输出身份包含起报信息。
- 未知颜色、不同索引调色板、透明像素、缺瓦片与裁剪边界：分别保留科学含义，不以零值填平问题。
- 跨日期变更线的区域请求：v1 拒绝并提示拆分；二维曲线网格不能冒充规则网格。
- 缓存仅有拼接图但请求原始瓦片：重新获取缺少资料后才能判定完成。
- 缓存借用与回收同时发生、缓存索引损坏：不得删除在用数据，应恢复或重新获取。
- 发布完成清单前断网、取消或写入失败：不能被后续任务当作成功跳过。
- 输出目录被多个本地任务写入：报告锁冲突；远端并发写不在 v1 保证范围。
- 临时文件释放后继续使用返回数据：数据仍必须可读；取消任务不能迟到提交成功。
- 来源名称重复、可选依赖缺失、凭据失效：分别明确报错，不覆盖已有来源或破坏目录查询。

## Requirements *(mandatory)*

### Functional Requirements

以下要求均为 v1 必需；P2 仅表示交付顺序，不表示可省略。命令、文件格式和存储名称是用户可见兼容性要求，内部模块与技术选型由实施计划规定。

- **FR-001**: 系统必须提供独立的来源目录和单帧/批量使用入口，不依赖旧生产监控、消息队列、配置中心或业务数据库。（US1、US6）
- **FR-002**: 目录必须离线可查且稳定排序，包含来源描述、产品、站点、版本、依赖、可用状态；产品包含变量、单位、网格、更新频率、发布延迟、历史/预报能力和建议时效。实时探测必须由用户显式触发。（US1）
- **FR-003**: 最新、精确时次和时间区间必须恰选一种；时间必须带时区并统一到 UTC，区间为左闭右开，产品只有唯一默认项时才可省略。（US1）
- **FR-004**: 最新查询必须按来源/产品/站点确定并固定帧，支持最大年龄检查；精确查询不静默替代，单帧零匹配与多匹配分别报错。（US1）
- **FR-005**: 帧身份必须区分逻辑帧、上游修订和处理后输出，包含影响身份的定位信息及版本；临时路径、凭据、签名地址和并发设置不影响身份。（US3）
- **FR-006**: 获取必须校验内容完整性与时次对应关系，记录实际获取时间和版本；未知版本动态地址不能无限复用旧内容，也不能以获取时间替代有效时间。（US1、US3）
- **FR-007**: 原始资料必须具有唯一名称、角色、类型、大小和校验值；生命周期结束、失败和取消时释放临时资源，返回数据不依赖已删除文件。（US3、US5）
- **FR-008**: 科学结果必须区分单主要变量和真正多变量产品，包含质量、网格和处理来源；多变量共享网格和时间，异构产品分帧而非隐式对齐。（US2）
- **FR-009**: 数值必须保留物理含义及单位，雨强零仅代表已知无雨，等级保留类别映射；缺测、站外、未知颜色、恢复、插值和低于检测阈值均有可区分质量标记。（US2）
- **FR-010**: 能精确匹配的颜色不得默认模糊匹配，近似匹配必须有阈值，图像恢复必须有来源专属规则；严格模式拒绝未知颜色，宽容模式必须显式启用并记录缺测与数量。（US2）
- **FR-011**: 瓦片拼接与裁剪必须保持颜色和透明度，不引入插值或量化；不同调色板索引不能直接视为同色，缺瓦片默认失败，部分覆盖需来源明确允许。（US2）
- **FR-012**: 默认保留原生网格，明确像元中心、轴方向、坐标单位、空间参考和范围；必须支持地理、笛卡尔和极坐标网格，盘点发现曲线网格时纳入对应迁移批次。（US2、US6）
- **FR-013**: 空间转换必须显式请求并给出完整目标；类别仅最近邻，连续量默认最近邻、可选双线性，反射率须在线性域插值，缺测不得无约束扩散为有效值。（US2）
- **FR-014**: 使用者必须能够分别执行发现、获取原始资料、解码、写出，也能一次完成获取；同步与异步结果等价，错误调用方式有明确指引，获取默认不写正式输出。（US1、US5）
- **FR-015**: 批量默认收集全部逐帧结果并保序，重复帧输入拒绝；停止模式保留部分结果，流式模式按完成顺序、有界预取，导出报告不要求保留全部数组。（US5）
- **FR-016**: 默认下载必须输出 NetCDF 到 ./data，并支持 GeoTIFF、PNG、Zarr；NetCDF/Zarr 保留多变量及原生网格，GeoTIFF/PNG 限单变量可表达的规则二维栅格，需要时要求显式转换。（US1、US3）
- **FR-017**: 科学输出必须保留数值、质量、坐标、空间参考与处理来源；GeoTIFF 配套质量和来源信息，PNG 配套配色、范围与地理信息，Zarr 每帧独立保存。（US3）
- **FR-018**: 必须支持本地、Aliyun OSS 和 S3-compatible 输出；默认按来源、产品、日期、小时分区，名称包含站点或合成标识、有效时间、可选起报时间和处理变体。（US3）
- **FR-019**: 自定义输出模板必须限制在目标根目录内，只接受允许的字段；完整身份不同或短标识冲突不得静默覆盖。（US3）
- **FR-020**: 正式产物必须以包含完整身份、处理说明、文件清单、大小和校验值的最终完成清单判定成功；缺失或不完整清单允许修复，匹配完整产物可跳过，可变来源须重新校验。（US3）
- **FR-021**: 显式覆盖必须重新获取或校验上游；失败或取消不得发布成功清单，本地同根目录仅允许单写者，对象存储替代版本提交后旧版本保留至显式清理。（US3）
- **FR-022**: raw 表示正式保存全部原始资料；raw-only 仅保存原始资料及可离线重放的清单，不解码、拼接或重网格；两种模式互斥，已有解码产物不能替代 raw 完整性要求。（US3）
- **FR-023**: 缓存必须可关闭、可换目录、可查询、可预览回收及可清空；默认上限 20GB、最长 30 天、回收间隔 24 小时，依次清理遗留临时数据、过期数据、最久未用数据；在用条目与正式输出不受清理影响。（US5）
- **FR-024**: 缓存必须识别版本、损坏及失效索引，允许恢复或重新获取，避免相同内容重复提交；单瓦片不长期缓存，拼接缓存不能冒充原始瓦片；非交互清空需显式确认参数。（US5）
- **FR-025**: 配置优先级必须为显式参数、指定配置文件、环境变量、随包默认；凭据链为认证兜底。未知字段报错、映射深度合并、列表整体替换，静态资源覆盖必须记录版本。（US5）
- **FR-026**: 必须限制并行帧、请求、处理工作、在途字节、单资料大小、像素和临时盘占用，超限报错；重试默认最多 3 次尝试，仅适用暂时性故障并尊重上游等待要求，单请求超时与整帧期限可区分。（US5）
- **FR-027**: 用户取消必须停止排队与可取消工作，丢弃无法立即停止的工作产生的迟到结果并清理资源，不发布成功输出。（US5）
- **FR-028**: 命令行必须支持来源/产品/站点查询、发现、下载、终端预览、配置检查、诊断和缓存维护；预演可发现和检查目标，但不能下载原始资料或写正式输出。（US1、US4、US5）
- **FR-029**: 除终端展示外，标准输出必须为最终人类报告或一个带版本的机器报告，包含运行标识、查询、计数、逐帧状态和错误；诊断走标准错误。退出状态必须区分成功/跳过 0、参数/配置/依赖 2、无数据/过期 3、部分失败 4、全部处理失败 5、中断 130。（US5）
- **FR-030**: 错误必须提供稳定类别、阶段、来源、帧标识、可重试性和说明；诊断应可追溯耗时、缓存命中、字节与重试，配置展示、报告、日志和清单不得泄露认证信息或完整签名地址。（US5）
- **FR-031**: 终端预览必须支持来源单帧或已有 NetCDF/PNG 文件，输入二选一；多帧、多变量必须明确选择，不接受范围播放、下载专属参数或机器报告模式。（US4）
- **FR-032**: 展示必须提供正确标题、色标、方向、比例与缺测区分，采用固定且版本化默认配色；显示调整不修改科学数据，缺失元信息标为未知，PNG 不重新着色或推断物理值。（US4）
- **FR-033**: 终端展示必须支持 Kitty、iTerm2、ANSI 与文字模式；自动探测有界且按支持能力降级，非交互默认在获取前拒绝图片展示，允许显式文字输出，取消后恢复终端状态。（US4）
- **FR-034**: 最小安装必须完成来源查询、基本获取和默认科学文件写出；重型功能按需安装，缺失依赖必须在下载前给出准确安装指引，不阻断其他来源。（US1）
- **FR-035**: 所有现有来源必须内置并纳入盘点，保留未来第三方扩展能力；同名来源必须拒绝注册，不能覆盖内置行为。（US6）
- **FR-036**: 每个迁移来源至少具备一个可追溯真实样本及发现、获取、解码验收，覆盖形状、类型、变量、单位、网格、缺测、参考像素或分布；默认回归不依赖公网，在线检查单列。（US6）
- **FR-037**: 迁移必须记录历史错误修正及行为差异，不要求旧接口、旧配置、旧生产集成或逐字节输出兼容；所有遗漏与不可获取项必须有证据，例外接受和完整验收前不得归档旧仓库。（US6）

### Key Entities *(include if feature involves data)*

- **来源与产品描述**：用户可查询的来源、站点、产品、能力、更新节奏、可用状态和可选依赖。
- **查询**：来源、产品、站点与互斥的时间选择，可附起报时间、最大年龄和空间请求。
- **帧引用**：不可变的逻辑帧描述，含有效时间、起报时间、版本化定位信息及已知修订；获取地址不是长期身份。
- **原始资料与获取回执**：命名资料及其大小、校验、获取时刻和内容版本，关联所获取帧；运行期资源与用户正式保存资料分开管理。
- **科学场与科学数据集**：一个或多个主要物理变量，以及同网格的质量、时间和处理来源。
- **网格**：表达空间位置、形状、坐标方向、空间参考及必要几何假设；显式转换生成新处理记录。
- **处理记录与输出身份**：关联输入修订、解码及资源版本、变量、网格变换和输出选项，支持追溯与复用判断。
- **输出组与完成清单**：正式文件、原始资料及其完整性证明；最后发布的清单决定是否完成。
- **逐帧结果与批量报告**：包含帧标识、成功/跳过/失败、数据或输出位置及错误，不丢弃失败项。
- **迁移盘点与例外**：旧来源的状态、证据、真实样本、迁移去向、差异和接受结论。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 旧仓库全部来源（含未启用及注释项）100% 具有迁移去向或有证据且已接受的例外，未解释遗漏为 0。（FR-035～037）
- **SC-002**: 每个非例外来源至少 1 个真实样本通过发现、获取、科学解释验收，声明在线可用来源均可由统一入口访问；六类获取/解码来源各至少 1 个代表完成独立验收。（FR-001～014、036）
- **SC-003**: 固定验收集中的时间边界、时效、歧义、起报冲突和动态内容竞态全部按预期处理，误选时次或把旧帧当最新帧的案例为 0。（FR-003～006）
- **SC-004**: 固定科学验收集的有雨、无雨、缺测、站外、未知颜色和无回波状态全部正确区分；参考像素、几何控制点和文件读回均满足逐样本事先记录的精度容差，错误变为降水零值的案例为 0。（FR-008～013、016～017）
- **SC-005**: 三类输出目标分别通过首次保存、有效跳过、冲突、覆盖、中断恢复及三种原始资料保存模式验收；故障注入中假成功清单和静默错误覆盖均为 0。（FR-018～022）
- **SC-006**: 每个批量输入帧都对应可追溯结果或带原因的未完成状态；失败遗漏为 0，取消后成功提交为 0；流式验收在固定预取上限下不保留随总帧数增长的未消费结果集合。（FR-015、026～030）
- **SC-007**: 缓存损坏、并发访问和回收验收全部通过，正式文件或在用资料被误删数量为 0；开启与关闭缓存所得科学结果一致。（FR-023～024）
- **SC-008**: 四种声明展示模式均通过发布前验收，ANSI 及两种图片协议分别有真实终端目视记录；非交互图片控制序列泄漏为 0，预览导致的科学数据变化为 0。（FR-031～033）
- **SC-009**: 在每个声明支持的安装环境，用户按文档可完成“列出来源—获取样本—默认导出—读回—预览”闭环；最小安装不要求未使用功能的重型依赖，默认回归运行无需公网。（FR-002、014、028、034、036）
- **SC-010**: 配置优先级、缺依赖提示、机器报告与全部退出状态的验收案例 100% 通过；审查样本日志、配置展示和输出清单中认证信息泄漏为 0。（FR-025、029～030、034）
- **SC-011**: 所有六类代表来源记录吞吐、峰值内存、请求数量和临时盘峰值；旧系统可运行时完成同条件基线比较，否则记录无法比较的原因，不以未测量加速比例作为完成证据。（FR-026、036～037）
