# Feature Specification: RDCAP 台湾、日本、菲律宾单站雷达支持

**Feature Branch**: `main`（当前分支；未配置分支创建 hook）

**Created**: 2026-10-01

**Status**: Draft

**Input**: User description: "$speckit-specify 新这个数据源几个国家雷达单站数据的支持"；“这个数据源”指本次会话分析的中央气象署亚太雷达资料中心 RDCAP，国家范围为台湾、日本、菲律宾。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 找到三国站点及近期时次 (Priority: P1)

值班用户在 radiust 来源目录中找到 RDCAP，查询三国单站目录，选择国家和站点，查看最新及近期可用回波时次。目录状态与当前资料状态分别展示。

**Why this priority**: 可选择的稳定站点身份和真实时间线，是获取单站资料的入口。

**Independent Test**: 使用三国站点目录和时间线回放，查询来源、站点与时次，无需下载回波文件即可核对身份、重复记录、时区和逐站状态。

**Acceptance Scenarios**:

1. **Given** 新来源已登记，**When** 查询来源与产品，**Then** 出现独立来源 `rdcap` 和默认单站产品 `reflectivity`，明确提供方、三国覆盖和近期时次能力，既有来源身份与产品保持原含义。
2. **Given** 三国目录回放含 13 个台湾站码、20 个日本站码和 16 条菲律宾记录，**When** 查询站点，**Then** 展示 48 个唯一的国家/站码组合，重复的菲律宾 BALE 合并为一个可选择身份，保留目录状态冲突说明。
3. **Given** 选择 `TWRCHL`、`JPISHI` 或 `PHSUBI`，**When** 发现最新资料，**Then** 每站独立选取自身最新可用时次，返回实际观测时间及完整来源、产品、站点身份。
4. **Given** 时间线含秒级、非等间距时刻或缺口，**When** 查询索引内指定时刻或时间范围，**Then** 按已有时间选择规则返回实际匹配帧并稳定排序，不依据显示分钟或固定周期制造时次。
5. **Given** APAR 目录标为活跃但当前没有资料，**When** 发现该站或全部站点，**Then** APAR 单独返回无数据状态，其他站点继续返回各自结果，目录活跃状态不覆盖发现状态。

---

### User Story 2 - 保存可离线重放的原始单站资料 (Priority: P1)

数据使用者选择单站和近期时次，保存原始资料及来源记录。临时下载凭据变化或只可读取一次时，工具在有限重试内获取所选帧，已保存内容可离线复用。

**Why this priority**: 可验证原始资料及时间绑定是可信数值解码的基础；页面显示成功不能代替工具自身获取能力。

**Independent Test**: 以原始资料模式下载三国代表帧，核对原始字节、站点与观测时刻，断网后重放；模拟临时凭据失效、空内容和超时，独立核对获取状态。

**Acceptance Scenarios**:

1. **Given** 已启用项目联网能力且所选站有资料，**When** 保存该站原始帧，**Then** 成果包含未经改写的提供者内容、完整解读元信息和实际观测时间，无需用户手工打开 Orca 或复制临时凭据。
2. **Given** 所选帧的临时下载凭据已消费或失效，**When** 获取该帧，**Then** 在共享操作预算内重新申请凭据，仍匹配原站点和原时刻，不静默改为另一帧或无限重试。
3. **Given** 原时刻已移出近期窗口，**When** 重新申请凭据后仍无法定位该帧，**Then** 明确报告该帧不可获取，保留其他已完成帧的结果。
4. **Given** 同一逻辑帧已有可验证的完整成果，**When** 重复下载或离线重放，**Then** 按既有缓存和幂等规则复用成果，临时凭据变化不产生新帧身份。
5. **Given** 上游返回空文件、拒绝页面、超时或不可验证内容，**When** 保存原始资料，**Then** 返回明确且有界的失败结果，不提交成功清单，不以占位内容或测试样本冒充在线资料。

### User Story 3 - 得到正确单位与位置的回波数值和图像 (Priority: P1)

分析人员获取单站回波后，获得以 dBZ 表示的数值场，通过现有预览与输出能力检查回波位置。缺测、有效弱回波和范围圆等显示标记有明确区别，科学成果可由其他工具独立读回。

**Why this priority**: 数值网格是本来源的核心价值；错误单位、行方向、半格定位或标记解释会产生错误观测。

**Independent Test**: 离线解读花莲、石垣岛、苏比克真实原始帧，核对单位、网格、色标及已记录参考点，并独立读回导出成果。

**Acceptance Scenarios**:

1. **Given** 三国各一个已验证原始帧，**When** 获取回波数值，**Then** 返回提供者网格上的 dBZ 值、坐标、观测时间和来源记录，不将数值解码等同于已验证扫描高度或雨量推算。
2. **Given** 原始值含有效负值、缺测和显示标记，**When** 生成科学数值场，**Then** 有效弱回波保留，缺测与显示标记不成为零值或极端回波，标记排除依据和限制可追溯。
3. **Given** 网格使用已验证的像元左上角注册且原始行序南向北，**When** 导出或显示资料，**Then** 范围、坐标及像元中心与提供者网格一致，不上下镜像或偏移半格。
4. **Given** 同一已验证数值场，**When** 使用已有科学预览及 PNG、NetCDF、GeoTIFF、Zarr 输出，**Then** 适用成果保持正确时间、坐标、单位及质量；PNG 使用已验证色标，弱回波显示透明不导致科学值丢失。
5. **Given** 网格结构、单位、数值变换或标记模式超出已验证范围，**When** 请求科学解码，**Then** 明确拒绝未经验证的解释；合法取得的原始资料仍可保留供核查。

### User Story 4 - 使用现有批量与编程工作流 (Priority: P2)

自动化用户通过既有命令行及同步、异步编程入口选择多个单站，执行发现、获取、下载及重放，逐站区分成功、无数据、过旧及失败结果。

**Why this priority**: 新来源需融入现有资料工作流，支持跨国巡检，不能只提供专用研究脚本。

**Independent Test**: 同时查询三国成功与无数据站点，分别通过命令行和编程入口核对身份、逐目标状态及成果，同时回归已有台湾和菲律宾来源行为。

**Acceptance Scenarios**:

1. **Given** 选择三国多个站点，**When** 批量发现或下载，**Then** 每个唯一来源/产品/站点目标都有确定结果，统计不因目录重复增加，部分失败不隐藏已成功项。
2. **Given** 未选择站点，**When** 发现或下载新来源，**Then** 展开三国全部唯一站点并遵守共享预算；只接受单帧的获取或预览在多匹配时提示选择站点/时次，不任意选取。
3. **Given** 同一合法查询分别经命令行、同步及异步入口运行，**When** 获取相同帧，**Then** 逻辑身份、时间、数值、坐标和质量等价，失败类别一致。
4. **Given** 资料过旧、查询超时或用户取消，**When** 达到既有时效或预算限制，**Then** 保留已完成项、标明其余项状态，并按已有收尾及资源清理约定结束。

### Edge Cases

- 同国家/站码多条记录且状态冲突：合并查询身份，保留冲突说明，不因活跃标签推断有数据。
- 不同国家站码相同、仅输入短站码或国家不匹配：按完整身份匹配；短站码只有唯一匹配时可接受，歧义或错误身份提示合法候选。
- 三国共用网站参考时间但当地时区不同：保留实际时刻，不能按日本当地时区再次偏移；显示必须带时区。
- 时间线为空、仅一帧、间隔十几秒、长缺口、乱序或重复：保留实际时间；完全相同逻辑记录去重，不一致的同身份候选返回歧义。
- 目录列出停用站、新站或暂时无资料站：保留身份及已知状态，不把当前在线站点冻结为永久支持白名单。
- 最新帧落后当前时间：保留观测时间并沿用时效限制，不用下载时间替代。
- 凭据首读后失效、被预读或刷新索引后帧变化：复用已保存内容，必要时为原帧重新申请凭据，不换帧。
- 历史查询返回拒绝页面但传输表面成功：仍为错误内容；窗口外查询不能冒充已经支持长期归档。
- 稀疏资料元素数量或位置不合法、头与数值不匹配、截断或超大网格：拒绝损坏资料，遵守既有资源限制。
- `-999` 缺测、有效负值、低于 5 dBZ 的弱回波、`9999` 白色范围圆/站心标记并存：不能把透明、缺测、无雨和显示标记混成同一种科学值。
- 全帧只有标记或缺测：允许形成没有有效回波观测的场，不伪造零反射率，也不据缺测判断无降水。
- 网格范围、分辨率、像元注册、数值单位或标记模式变化：以当前帧元信息和已验证规则为准，不套用另一站几何。
- 多国多站共享输出根目录：完整逻辑身份防止覆盖；国家分隔符不能绕过已有输出路径约束。
- 站点坐标缺失：元信息明确未知，不能从站点中心猜造科学网格坐标。
- 上游不可访问、证书失败、预算耗尽或取消：明确报告限制，沿用网络配置，不静默降低保护或要求用户维持外部浏览器会话。

## Requirements *(mandatory)*

### Functional Requirements

来源、产品及站点标识属于用户可见契约；内部请求方式、格式解析方法及组件设计由后续计划确定。

- **FR-001**: 系统 MUST 新增独立来源 `rdcap`，提供默认产品 `reflectivity`，国家范围仅为台湾、日本、菲律宾，支持这些国家的单站选择。（US1）
- **FR-002**: 系统 MUST 以 `TW<站码>`、`JP<站码>`、`PH<站码>` 返回稳定站点身份，目录提供可证实的站名、国家、坐标和提供者状态；短站码仅唯一匹配时可接受。（US1；身份歧义边界）
- **FR-003**: 系统 MUST 按国家/站码合并目录重复记录，保留冲突状态与证据，分别表示目录状态和当前资料状态；新增或暂时无资料站点仍保留身份。（US1）
- **FR-004**: 用户 MUST 能查询每站最新帧、近期时次及索引内指定时刻/时间范围，使用实际时次并沿用现有匹配及最新资料时效规则。（US1）
- **FR-005**: 系统 MUST 保留秒级及更细的实际时间精度，以带时区的时刻表示并维持既有统一时间语义；不能用显示分钟、固定扫描周期或获取时间重建观测时间。（US1）
- **FR-006**: 系统 MUST 区分无数据、过旧、站点未知、时间无匹配及无法唯一匹配的结果，一个站点失败不能改写其他站点状态。（US1、US4）
- **FR-007**: 用户 MUST 能通过现有原始资料保存模式获取单站帧，保留未改写的提供者内容、完整解读元信息、提供方、国家、站点、产品和实际观测时间。（US2）
- **FR-008**: 系统 MUST 自动完成合法在线获取，用户不需手工复制临时凭据或维持 Orca 页面；联网权限、证书验证及访问限制遵循现有配置。（US2）
- **FR-009**: 系统 MUST 将临时凭据作为可失效的获取条件而非帧身份，复用已保存首读内容，重取凭据后仍绑定原逻辑帧，所有尝试遵守共享操作与重试预算。（US2）
- **FR-010**: 系统 MUST 校验返回内容与所选帧的可验证性，空内容、拒绝页面、损坏资料、已消失时刻或绑定不足不能提交成功成果；不得用最新帧、占位图或样本替代在线目标帧。（US2）
- **FR-011**: 系统 MUST 独立记录原始获取、数值解码与显示能力；只有单位、时间绑定、网格注册、标记处理及参考值均有证据时，才能声明科学数值可用。（US2、US3）
- **FR-012**: 系统 MUST 根据当前帧声明恢复回波网格与 dBZ 数值，正确处理未显式保存位置和无效值；不支持的结构、单位或变换明确拒绝，合法原始资料仍可保留。（US3）
- **FR-013**: 系统 MUST 保留有效负 dBZ 及低于显示阈值的回波，缺测不能变零；依据已验证规则识别的范围圆和站心标记须从科学回波中排除，并记录角色与判定依据。（US3）
- **FR-014**: 系统 MUST 保存 `9999` 标记处理的实测依据及推断性质，保留原始值；不能冒称提供者正式缺测定义，也不能将其输出为极端科学回波。（US3）
- **FR-015**: 系统 MUST 保持每站当前帧的坐标、行方向、像元注册、范围及分辨率一致，不套用另一资料集或站点的几何；显式转换网格沿用已有坐标与质量规则。（US3）
- **FR-016**: 系统 MUST 使用已验证回波色标，区分科学值与显示透明度；默认科学预览不将已排除标记恢复为气象回波。（US3）
- **FR-017**: 用户 MUST 能通过已有数值获取、科学预览及 PNG、NetCDF、GeoTIFF、Zarr 输出使用已验证单站资料；适用成果保留身份、单位、质量、坐标和来源，科学格式可独立读回。（US3）
- **FR-018**: 系统 MUST 支持现有命令行及同步、异步编程入口，保持同查询身份、时间、数值、坐标、质量和失败类别等价，沿用原始资料上下文与结果生命周期规则。（US4）
- **FR-019**: 系统 MUST 在未指定站点的来源发现/下载及全来源发现中展开三国全部唯一单站目标；显式多站选择同样参与已有报告、稳定排序及统计，单帧操作沿用歧义检查。（US4）
- **FR-020**: 系统 MUST 使用来源/产品/国家站点/观测时间完整成果身份，临时凭据变化不改变身份；遵守既有缓存、幂等提交、输出路径、部分失败和取消清理规则。（US2、US4）
- **FR-021**: 系统 MUST 分别报告无数据、过旧、上游错误、超时、访问受限、解码未验证及取消，错误和公开来源记录不能泄露可复用凭据；机器报告保持已有契约。（US2、US4）
- **FR-022**: 系统 MUST 限定近期时间查询能力，归档历史、体扫、仰角/高度、风场、国家拼图和其他国家不在本次声明内；不能从默认回波推断已知扫描高度或定量雨强。（US1、US3）
- **FR-023**: 系统 MUST 保持 `tw`、`tw-http`、`ph` 及其他现有来源的身份、默认产品与既有行为，新增 RDCAP 不替换或重新解释已有来源。（US1、US4）
- **FR-024**: 交付 MUST 提供三国代表帧、目录/时间线和异常资料的可重放证据，分别记录离线解码与工具自身在线获取验证；上游不可达不能用回放通过替代在线验收。（US1–US4）

### Key Entities *(include if feature involves data)*

- **来源**：RDCAP 的公开身份、提供者、国家覆盖及独立能力状态，与已有地区来源区分。
- **单站**：国家和站码组成的稳定身份，关联名称、可证实坐标、目录状态及冲突说明。
- **单站回波产品**：提供者回波网格，变量为反射率、单位为 dBZ；扫描高度与上游处理方法可明确未知。
- **时间线与帧引用**：站点近期实际时刻和选择信息；来源、产品、站点、观测时刻组成帧身份，临时凭据不参与身份。
- **原始资料**：未改写的提供者内容、解读元信息和时间绑定证据，支持保存与离线重放。
- **回波数值场**：具有单位、地理位置、时间、质量及来源的科学值，区分缺测、弱回波和被排除标记。
- **显示标记证据**：标记原始值、空间分布、排除规则与实测推断限制，可追溯处理前内容。
- **逐目标结果与成果**：发现、获取、解码、输出状态和可验证身份，用于批量、重试、缓存及能力验收。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 用户能查询并唯一选择已留存目录中的全部 48 个国家/站码身份，重复 BALE 不增加目标；所有状态冲突和无资料案例均有可见说明。（US1；FR-001–003、019）
- **SC-002**: 含秒级邻近、缺口、乱序、重复和过旧的时间线回放中，最新、指定时刻与范围查询的匹配身份及实际时间 100% 符合预期，无合成时次。（US1；FR-004–006）
- **SC-003**: 在显式启用联网且站点可访问的环境中，三国各至少一个当前有资料单站，通过 radiust 标准入口完成发现、原始获取、解码和一次科学成果读回，全程无用户手工 Orca 操作或凭据复制，留存日期及帧身份；任一国家缺此证据时，其在线支持仍标为未验收。（US2、US3；FR-007–012、024）
- **SC-004**: 对三国各至少一帧真实样本，数值符合提供者声明；花莲已记录 8 个地理取值与参考结果一致，有效值误差不大于 0.01 dBZ，缺测判定一致；三国原生注册、范围、中心位置和行方向与验证基准一致，导出坐标误差不大于原生格距的百万分之一。（US3；FR-012–015）
- **SC-005**: 缺测、有效负值、弱回波、范围圆及站心回放全部保持正确角色，100% 已验证显示标记不成为有效科学回波，真实弱回波不因透明而丢失，三国 PNG 色阶与基准一致。（US3；FR-013–016）
- **SC-006**: 同组三国资料经现有预览与四种要求的格式输出后，科学文件独立读回的时间、单位、坐标、有效值及缺测一致；重复下载全部复用已验证完整成果，不因临时凭据变化重复提交。（US2、US3；FR-017、020）

## Assumptions

- 国家范围沿用会话中分析的台湾、日本、菲律宾；默认采用一个新增来源 `rdcap`、一个产品 `reflectivity`，站点使用带国家身份。其他国家、国家拼图、仰角/风场及长期归档不在本次范围。
- 既有目录、时间选择、编程入口、质量、输出、缓存、网络预算与报告契约作为基础；新增来源不扩大共享功能语义，不重写其他规格实现范围。
- 目录和可用性由提供者决定，实测数量不是未来硬编码上限；未知站点属性、扫描高度与上游处理含义明确未知，不推算雨量或特定高度反射率。
- [分析报告](../../docs/rdcap-single-station-analysis.md) 与 [实测资料](../../validation-results/rdcap-analysis/) 是研究输入，覆盖三国原始数值、几何注册、色标、参考点及一次读取行为；内部请求与解析设计由后续研究/计划确定。
- 当前已验证浏览器中的三国文件获取、独立索引获取和本地解码；浏览器外完整文件获取超时，工具自身在线获取尚未验收。计划须解决或如实保留该阻塞，不能把研究样本视为实施完成。
- `9999` 作为显示标记有当前样本和网页对照证据，但仍是实测推断，规则不自动推广到不同版本或其他产品；保留原始内容及限制说明。
- [项目宪章](../../.specify/memory/constitution.md) 仍为占位模板，未提供已批准原则；本规格使用现有规格中的用户契约和证据边界，不将宪章示例作为要求。
