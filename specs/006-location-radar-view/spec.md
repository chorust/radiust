# Feature Specification: 位置驱动的雷达发现与局部投影预览

**Feature Branch**: `main`（当前分支；特性标识 `006-location-radar-view`）

**Created**: 2026-10-09

**Last Updated**: 2026-10-24

**Status**: 已实施 — 53/53 项任务完成。离线证据覆盖三个用户故事；安装后裸 `cat` 当前链路成功发现、获取并生成 RainViewer 局部 dBZ 视图，适用范围为个人用途 `local_view`，终端报告显示 RainViewer 署名和链接。SC-001–008 均在规格范围内满足。Madeira 测试点的观测覆盖仍未知；不声明其他地区已覆盖，商用/高流量用途和底层资料再分发不在本次准入范围内。

**Input**: 用户希望以配置的所在位置发现覆盖该位置的雷达，将观测转换为用户居中的笛卡尔坐标图；范围可配置，例如 50 km；`cat` 不指定 source/station 时自动发现并展示。本次要求主要设计投影转换与雷达站表，并用 Tropical Globe 导出的 CSV 交叉核对站点。

## User Scenarios & Testing

### User Story 1 - 一条命令查看自己附近的观测 (Priority: P1)

用户配置所在位置后，运行 `radiust cat` 即可查看附近的最新有效雷达观测，不必先知道来源、产品或站码。

**Why this priority**: 把用户关心的地点直接连接到观测，是 CLI 和未来 Desktop 共同的默认流程。

**Independent Test**: 使用受控目录与观测回放，配置位置并执行裸 `cat`，检查实际选择、有效时间、局部图和失败状态。

**Acceptance Scenarios**:

1. **Given** 已配置位置，且有满足访问条件、可靠定位和时间要求的产品，**When** 执行裸 `cat`，**Then** 自动发现并展示一个适用产品，说明来源、产品、站点或合成产品身份、有效时间和选择原因。
2. **Given** 位置未配置、仅配置一个坐标或坐标无效，**When** 执行裸 `cat`，**Then** 在联网前给出可理解的配置提示，不猜测位置。
3. **Given** 首选目标无数据、过期或获取失败，**When** 存在适用备用产品，**Then** 有界尝试备用并显示切换原因；所有尝试失败时保留真实结果。
4. **Given** 用户显式选择来源、站点或本地文件，**When** 运行现有命令，**Then** 保留原有入口语义；只有显式请求局部视图时增加位置投影，不静默启用新的处理模式。
5. **Given** 用户未允许联网或适用来源需要尚未配置的凭据，**When** 请求位置视图，**Then** 明确说明限制，不自动开启网络或访问例外。
6. **Given** 用户只允许一个来源，**When** 该来源失败，**Then** 报告该来源的真实失败，不切换到限制以外的来源。

### User Story 2 - 按实际距离查看用户居中的图 (Priority: P1)

用户希望图像中心就是自己，横纵方向分别表示东西与南北，距离可读且范围可调。

**Why this priority**: 把完整雷达产品转成与用户有关的局部图，是这项体验的主要价值。

**Independent Test**: 用已知地理位置和数值的观测回放检查中心、距离、方位、范围、像元方向与无覆盖区域。

**Acceptance Scenarios**:

1. **Given** 范围为半径 50 km，**When** 显示局部图，**Then** 用户位于 `(0,0)`，x 向东、y 向北，两轴像元中心覆盖 `−50～+50 km`，圆形范围外明确不属于本次视图。
2. **Given** 用户调整范围或显示网格间距，**When** 重新预览，**Then** 保持中心与距离语义，报告实际网格间距；不能把更密的输出称为上游分辨率提高。
3. **Given** 源产品几何不可信，**When** 请求局部图，**Then** 明确报告不可投影；源原图仍可通过原有显式入口查看，不冒充投影成功。
4. **Given** 原图有可靠几何但未验证物理色标，**When** 展示投影图像，**Then** 保留提供方图例与原图能力标识，不输出由颜色猜测的精确反射率或雨强。
5. **Given** 数值观测存在缺测、图面标记或产品无覆盖区域，**When** 投影，**Then** 保留质量状态；黑色、透明或缺测均不能被统一解释为无降雨。
6. **Given** 用户请求的数值解释没有验证依据，**When** 请求局部数值图，**Then** 说明能力不足，不用原图或颜色估值冒充数值结果。
7. **Given** 改变中心、范围或网格间距，**When** 查看同一次观测，**Then** 保留原始观测时间、来源和值的依据，并报告新视图的参数。
8. **Given** 产品可以可靠定位但扫描覆盖未知，**When** 展示其域内局部图，**Then** 标明覆盖未知，并与已知无覆盖和当前缺测分别呈现。

### User Story 3 - 查清哪些站点和产品可能适用 (Priority: P1)

维护者需要一份可追溯的目录，区分实体雷达站、区域选择器和已发布合成产品，支持按位置筛选并解释能力缺口。

**Why this priority**: 错误的站址或覆盖会导致错误选择，即使投影计算本身正确。

**Independent Test**: 对仓库现有目录和来源资源逐条核对身份、坐标出处、状态和产品关系，在不联网时检查筛选结果及排除原因。

**Acceptance Scenarios**:

1. **Given** RDCAP 目录的 48 个唯一站点、BMKG/SIDARMA 的 47 条历史站址记录和两个马来西亚区域选择器，**When** 整理目录，**Then** 每条保留出处与身份类别，不宣称这些记录代表已可用的 97 个实体站。
2. **Given** 同一站通过多个渠道提供产品，或同名/同码出现在不同来源，**When** 关联目录，**Then** 保留来源内身份，只有证据支持时才建立物理站关联，不按名称或距离自动合并。
3. **Given** 有站点坐标但没有可靠覆盖范围，**When** 自动发现候选，**Then** 最多列为待探测目标；不得据“最近”直接宣称覆盖。
4. **Given** 产品已发布为合成图或区域图，**When** 按位置筛选，**Then** 按产品覆盖处理，不虚构一个合成图中心作为实体雷达站。
5. **Given** 目录活跃但当前无数据、坐标冲突或来源退役，**When** 选择目标，**Then** 分别保留目录、观测和准入状态；不作为正常默认成功结果。
6. **Given** 外部站表有隐藏类别、共址雷达或迁站记录，**When** 交叉核对，**Then** 保留导出过滤条件、日期、身份候选与差异；外表一行、最近坐标或缺行均不自动合并、覆盖或删除本地站点。
7. **Given** 固定站身份或位置未确认，或条目可能属于移动雷达，**When** 整理目录，**Then** 明确保留未确认类别，不能以历史位置作为当前固定站址排序。

### Edge Cases

- 跨日期变更线、高纬度、中心恰在范围边缘、升降序源坐标、像元中心与像元边缘注册差异。
- 源网格外框覆盖用户，但有效观测区域不覆盖；整帧缺测但仍可能属于观测区域。
- 两个来源提供相同站点，物理量、图例、时间和覆盖不同；一次只展示一个产品。
- 全部来源需凭据、未获准自动启用或使用非默认 TLS 例外；不得自动配置访问例外。
- 半径或网格间距无效、网格数量溢出、超资源预算、取消、共享期限耗尽。
- 数据有效但全部低于显示阈值；不能因图像看起来空白而切换来源或判无数据。
- 目录刷新失败、旧覆盖快照与当前帧不同、站点搬迁与坐标修订。
- 共址雷达在外表合为一行；旧站比新站更近；移动雷达只留有历史位置。
- 圆形范围仅被一个产品部分覆盖；已知覆盖外与覆盖未知分别显示。
- 用户显式限制来源后的失败、请求数值但只有原图、局部模式与不受支持的文件或历史时间请求组合。
- 获取和处理期间取消、全部候选失败、达到候选上限但仍有未尝试目标。

## Requirements

### Functional Requirements

- **FR-001**: 用户可配置成对的有效经纬度、局部范围半径和网格间距；位置缺失、单坐标、非有限数值、越界坐标、无效范围或间距须在联网前拒绝并给出配置提示。
- **FR-002**: 裸 `cat` 以配置位置自动发现最新适用观测并展示局部图；用户可显式限制来源和查询目标，选择与回退不得越过这些限制。已有 source/file 入口不被位置配置隐式改变；不支持的局部模式组合须明确拒绝。
- **FR-003**: 获取、保存和处理默认在用户设备完成，不强制依赖 Radiust 账号或项目数据中转服务；遵守现有网络许可、凭据、请求限额及访问条件，不自动启用网络、配置凭据或放宽访问保护。
- **FR-004**: 站表区分实体站、区域选择器、产品选择器、合成产品及未确认类别；身份在来源内稳定，跨渠道关联须有证据。移动或固定位置未确认的条目不得按历史位置参与固定站排序。
- **FR-005**: 坐标、覆盖、像元定位、在线观测、数值解释和访问准入分别记录出处、日期与状态；外部目录核对保留快照、过滤条件、关系与冲突，目录标记或范围值不替代这些证据。
- **FR-006**: 候选按请求位置、覆盖证据、访问条件及请求的数据能力筛选，同等适用条件下优先官方产品；站点距离仅用于有限候选探测或同等级排序，不单独证明覆盖。
- **FR-007**: 区分产品发布外框、真实观测覆盖和当前缺测；外框或有色像素不能推导完整观测覆盖。
- **FR-008**: 首选与回退必须可解释；明确展示排除/尝试/切换原因、实际产品与有效时间。无数据、过期、失败、不适用和未尝试分别报告；候选截断时不能声称已穷尽所有覆盖。
- **FR-009**: 局部图以用户为原点，x 向东、y 向北，距离轴用 km；范围按半径解释，范围外与来源无覆盖分别标识。
- **FR-010**: 中心、距离和方位满足独立地理参考的精度要求；源像元位置和行列方向保持正确，不发生镜像、旋转或错行。显示网格变密不能宣称上游真实分辨率提高。
- **FR-011**: 只有可靠定位且转换受支持的产品可输出局部图；不支持的基准面转换必须拒绝，不能重新标注坐标来代替转换。
- **FR-012**: 数值与原图分别保留能力、物理量、单位、质量和图例；局部图不自动提高科学能力。用户明确请求数值解释时，能力不足须报告失败，不以原图或未经验证的颜色估值代替。
- **FR-013**: 默认采样保留选中原始像元的观测值和质量类别；受支持的连续数值插值须由用户显式选择并保留物理含义。质量类别不得平均，原图颜色不得被用于推断未经验证的物理量。
- **FR-014**: 缺测、无覆盖、低于阈值、恢复值及图面标记继续可追溯；局部处理不伪造无雨或新观测时间。
- **FR-015**: 报告保留中心、范围、实际间距、投影、源身份、有效时间和处理版本；来源变化同步更新图例、覆盖和时间。
- **FR-016**: 改变视图中心、范围或采样设置不得改写原始观测；不同视图可区分其参数与输入观测。缓存命中、重新获取和局部处理均不能更新观测有效时间。
- **FR-017**: 全流程有统一请求、处理和资源限额，失败回退不重置总期限；可由请求确定的超限在资源分配或联网前拒绝，获取或处理期间发生的超限须停止相应工作。取消或总期限耗尽后停止启动新工作，不发布迟到成功结果，并保留已完成与未尝试目标的真实状态。
- **FR-018**: 同一请求通过命令行、同步或异步程序接口得到一致的源选择、位置网格、观测值、质量及错误含义；公众后续入口复用这些结果语义。

### Key Entities

- **用户位置与视图请求**：中心经纬度、半径、网格间距、可选来源限制。
- **站点/查询目标记录**：来源内身份、类别、坐标与出处、适用产品、目录状态。
- **产品空间能力**：覆盖种类、发布外框、源定位、坐标基准、验证记录与准入状态。
- **候选与选择记录**：几何适用性、访问状态、探测顺序、实际终态和最终选择。
- **局部观测视图**：投影网格、图像或数值、质量/范围掩码、真实时间、来源与处理历史。

## Success Criteria

### Measurable Outcomes

- **SC-001**: 在受控场景中，配置位置后只需一条裸 `cat` 命令即可完成最新观测发现到局部展示，无需输入来源或站码；缺位置、禁网、缺凭据、无适用来源和过期场景全部给出正确结果。
- **SC-002**: 半径 50 km 的参考点在局部图的距离误差不超过 1 m；东西南北方位、中心与行列方向全部正确。算法误差与源定位误差分别报告。
- **SC-003**: 现有 48 个 RDCAP 站点、47 条 SIDARMA 历史站址及相关来源选择器逐项留有整理记录，95 条站址候选保留 Tropical Globe CSV 交叉核对结果与冲突；没有由距离、名称、外表 range 或外框推导的虚假覆盖结论。
- **SC-004**: 半径 10/50/200/500 km 的四个正向方位和四个斜向方位，以及日期线、高纬度、极点场景，全部满足独立参考的中心/距离精度要求；方向、源样本位置和范围边界没有反转或错位。
- **SC-005**: 首选成功、回退成功、全部失败、部分覆盖、整帧缺测和显示阈值以下观测六类场景全部保留正确时间、质量和来源；缺测或低于阈值触发的错误切源、虚构无雨和伪造新观测时间均为 0 次。
- **SC-006**: 命令行与同步/异步程序接口对相同请求的源选择、位置网格、观测值、质量和错误含义 100% 一致；显式 source/file 的既有代表流程结果符合原有约定，来源限制外的回退为 0 次。
- **SC-007**: 可由请求确定的超限全部在分配或联网前拒绝，运行期间超限不发布成功结果；回退遵守整批期限，取消后 5 秒内完成受控验证中的收尾。
- **SC-008**: 首批默认产品至少有一个完整的访问准入、当前标准入口发现/获取和局部图验证记录；离线样本不能代替当前在线证据，未通过的地区/产品继续受限。

## Assumptions

- Core/CLI/SDK 的离线位置视图、投影采样和空间站表索引已实现；2026-10-17 固定 PT/RainViewer fixture 的成功/失败/模式/缓存场景已贯穿 CLI、同步 SDK、异步 SDK，数值与 quality 摘要逐入口精确一致。2026-10-24 裸 `cat` 当前链路通过，RainViewer 仅对个人用途的 `local_view` 自动准入并在 CLI 显示署名；测试点观测覆盖仍未知。Desktop UI、动画、预测、跨来源拼图和正式局部成果导出不属于本规格。
- 将 50 km 按半径定义，默认半径 50 km、请求网格间距 1 km；用户可配置覆盖这些默认值。
- 首轮仅展示最新的单个来源产品，半径大于 0 且不超过 500 km；不要求一个产品完整覆盖所选圆形范围，已知无覆盖与未知覆盖须可区分。
- 自动流程最多尝试 8 个目标，继承既有配置的整批期限与资源限额；达到上限须说明仍可能有未尝试目标。来源限制、局部文件和历史时间组合的详细行为见既有[入口设计](contracts/cli-sdk.md)。
- 使用手动配置的 WGS84 位置；不新增自动定位、地址解析或位置服务。
- 复用既有来源，先支持具有可靠源定位的观测；不要求补齐全球实体雷达站或所有来源科学解码才能交付。
- 001–005 的已有能力可复用，其全部历史验收不是前置；006 也不自动关闭它们的开放项。
- 默认启用的真实来源须先补准入证据；RDCAP 单站 TLS 例外与离线通过不自动取得默认准入资格。
- Tropical Globe 的导出日期、过滤条件及 95 条初筛结果以[已取得的目录核对报告](tropicalglobe-crosscheck.md)为依据；近距、共址或迁站候选仍须核实，当前不会由本规格自动修改生产站址或升级覆盖声明。
